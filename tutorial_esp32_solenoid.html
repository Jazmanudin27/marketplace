PERINGATAN KRUSIAL (JANGAN SAMPAI ESP32 TERBAKAR!)

LANGKAH WAJIB SEBELUM SAMBUNG KABEL KE ESP32: Modul Step-Down LM2596 harus disetel terlebih dahulu menggunakan obeng min (-) pada baut trimpot kuningan. Ukur terminal OUT+ dan OUT- dengan multimeter sampai terbaca TEPAT 5.0 VOLT. Jangan pernah menyambungkan output step-down ke ESP32 sebelum memastikan tegangannya sudah 5V, karena tegangan default pabrik bisa mencapai 11V–12V yang langsung merusak board ESP32 Anda!

⚡ Logika Active-LOW

Relay menyala saat diberi logika LOW (0V) dan mati saat diberi HIGH (3.3V).

🚰 Polaritas Solenoid

Kumparan Solenoid DC 12V tidak memiliki kutub plus-minus terbalik, 2 pin bebas ditukar.

🔌 Common Ground

Semua pin GND (-V PSU, IN-, OUT-, GND ESP32, GND Relay) saling terhubung.

🛠️
6 Langkah Perakitan Step-by-Step
1

Pasang Kabel Steker AC ke Power Supply

Sambungkan kabel colokan listrik ke terminal L dan N pada PSU jaring. Pastikan sekrup kencang dan tidak ada serabut kawat yang saling menyentuh.

2

Hubungkan PSU ke Input Step-Down LM2596

Tarik kabel dari +V PSU ke IN+ Step-Down, dan dari -V PSU ke IN- Step-Down.

3

KALIBRASI TEGANGAN STEP-DOWN KE 5V (WAJIB!)

Colokkan steker PLN. Gunakan Multimeter pada pin OUT+ dan OUT-. Putar trimpot kuningan dengan obeng min sampai terbaca 5.0V. Setelah pas, cabut steker kembali.

4

Beri Daya ke ESP32 dan Modul Relay

Hubungkan OUT+ (5V) ke pin VIN ESP32 dan pin VCC Relay. Hubungkan OUT- (GND) ke pin GND ESP32 dan GND Relay.

5

Hubungkan Sinyal Kontrol ESP32 ke Relay

Sambungkan kabel jumper dari pin D4 (GPIO 4) ESP32 ke pin IN1 pada modul Relay.

6

Rangkai Jalur Beban Solenoid Valve 12V

Ambil kabel +V (12V) dari PSU ke terminal COM Relay 1. Dari terminal NO Relay 1 ke pin 1 Solenoid. Pin 2 Solenoid sambungkan ke -V (GND) PSU.

Contoh Program Arduino IDE (Buka-Tutup Solenoid Otomatis)
/* * TUTORIAL KONTROL SOLENOID VALVE 12V DENGAN ESP32 & RELAY * Pin D4 terhubung ke pin IN1 Modul Relay 5V * Catatan: Modul Relay umumnya ACTIVE-LOW (LOW = ON, HIGH = OFF) */ const int RELAY_PIN = 4; // GPIO 4 (Pin D4 pada board ESP32) void setup() { Serial.begin(115200); // Inisialisasi pin relay sebagai OUTPUT pinMode(RELAY_PIN, OUTPUT); // Set awal ke HIGH (Relay Mati / Kran Tertutup saat pertama dinyalakan) digitalWrite(RELAY_PIN, HIGH); Serial.println("Sistem Siap! Solenoid Valve dalam kondisi OFF (Tertutup)."); } void loop() { // BUKA KRAN AIR (Relay ON -> Solenoid 12V Aktif) Serial.println("Membuka Kran Air (Relay ON)..."); digitalWrite(RELAY_PIN, LOW); // Sinyal LOW mengaktifkan Relay Active-LOW delay(5000); // Kran terbuka selama 5 detik // TUTUP KRAN AIR (Relay OFF -> Solenoid 12V Mati) Serial.println("Menutup Kran Air (Relay OFF)..."); digitalWrite(RELAY_PIN, HIGH); // Sinyal HIGH mematikan Relay delay(5000); // Kran tertutup selama 5 detik }
