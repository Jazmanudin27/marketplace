Putar sekrup trimpot kuningan menggunakan obeng min (-) berlawanan arah jarum jam (sekitar 10-15 putaran) sambil mengukur pin OUT+ dan OUT- dengan multimeter hingga terbaca TEPAT 5.0 VOLT. Jangan pernah menghubungkan output step-down ke ESP32 sebelum tegangan 5V dipastikan aman!

6 Langkah Mudah Merakit Rangkaian
1

Pasang Kabel Steker AC ke Power Supply

Sambungkan kabel colokan listrik ke terminal L (Phase) dan N (Neutral) pada Switching PSU 12V. Kencangkan baut terminal.

2

Sambungkan Input Step-Down LM2596 ke PSU

Tarik kabel dari +V PSU ke IN+ Step-Down, dan dari -V PSU ke IN- Step-Down.

3

KALIBRASI TEGANGAN STEP-DOWN KE 5.0V (WAJIB!)

Colokkan steker PLN. Tempelkan Multimeter pada OUT+ dan OUT-. Putar baut trimpot kuningan dengan obeng min sampai terbaca 5.0V. Setelah tepat, cabut steker.

4

Beri Daya ke ESP32 dan Modul Relay

Hubungkan OUT+ (5V) ke pin VIN ESP32 dan pin VCC Relay. Hubungkan OUT- (GND) ke pin GND ESP32 dan GND Relay.

5

Sambungkan Kabel Kontrol ESP32 ke Relay

Gunakan kabel jumper DuPont untuk menghubungkan pin D4 (GPIO 4) ESP32 ke pin IN1 pada modul Relay 5V.

6

Rangkai Jalur Beban Solenoid Valve 12V

Tarik kabel dari +V (12V) PSU ke terminal COM Relay 1. Dari terminal NO Relay 1 sambungkan ke Pin 1 Solenoid. Pin 2 Solenoid sambungkan ke -V (GND) PSU.

Contoh Program Arduino IDE (Siap Upload ke ESP32)
/*
 * =========================================================================
 * PROYEK IoT: KONTROL SOLENOID VALVE 12V DENGAN ESP32 & RELAY 5V
 * Board: ESP32 Dev Module / NodeMCU ESP32
 * =========================================================================
 */

// Definisikan pin GPIO yang terhubung ke pin IN1 Modul Relay
const int RELAY_PIN = 4; // GPIO 4 (Pin D4 pada ESP32)

void setup() {
  Serial.begin(115200);
  delay(500);

  // Atur pin relay sebagai OUTPUT
  pinMode(RELAY_PIN, OUTPUT);

  // Inisialisasi awal ke HIGH (Relay Mati / Kran Tertutup saat alat dinyalakan)
  digitalWrite(RELAY_PIN, HIGH);

  Serial.println("================================================");
  Serial.println("Sistem Kran Air Otomatis ESP32 Siap!");
  Serial.println("Status Awal: KRAN TERTUTUP (OFF)");
  Serial.println("================================================");
}

void loop() {
  // 1. BUKA KRAN AIR (Relay ON)
  Serial.println("▶ [ON] Membuka Kran Air (Relay Aktif)...");
  digitalWrite(RELAY_PIN, LOW);   // Sinyal LOW mengaktifkan Relay (Active-LOW)
  delay(5000);                     // Kran terbuka mengalirkan air selama 5 detik

  // 2. TUTUP KRAN AIR (Relay OFF)
  Serial.println("⏸ [OFF] Menutup Kran Air (Relay Mati)...");
  digitalWrite(RELAY_PIN, HIGH);  // Sinyal HIGH mematikan Relay
  delay(5000);                     // Kran tertutup selama 5 detik
}
